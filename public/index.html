📊 Nasıl Çalışır?
• Para Girişi: Yüksek hacim + Pozitif fiyat değişimi (Alım baskısı)
• Para Çıkışı: Yüksek hacim + Negatif fiyat değişimi (Satış baskısı)
• Skor = Hacim × Fiyat Değişimi (Para akışı gücü)
